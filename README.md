# TUK 캐릭터 이동 프로그램

Python과 Pico2D로 TUK 배경 위의 캐릭터를 움직이는 프로그램입니다.

## 실행

Python과 Pico2D가 필요합니다. 이번 개발은 Windows, Python 3.14.7, 설치된 Pico2D 환경에서 검증했습니다. Pico2D가 없다면 설치합니다.

```powershell
python -m pip install pico2d
```

프로젝트 폴더에서 실행합니다.

```powershell
python character_move_TUK.py
```

`animation_sheet.png`와 `TUK_GROUND.png`는 실행 파일과 같은 폴더에 있어야 합니다. 이미지 경로는 실행 파일 위치를 기준으로 찾으므로, 다른 작업 폴더에서 실행 파일의 전체 경로로 실행해도 동작합니다.

## 조작과 동작

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동, 해당 방향으로 시선 전환 |
| ↑ / ↓ | 상하 이동, 직전 좌우 시선 유지 |
| 수평·수직 방향키 동시 입력 | 대각선 이동 |
| ESC / 창 닫기 | 종료 |

- 창 크기는 1280 × 1024, 캐릭터 프레임 크기는 100 × 100입니다.
- 캐릭터는 화면 중앙에서 오른쪽을 바라보며 IDLE 애니메이션으로 시작합니다.
- 이동 속도는 초당 200픽셀입니다. 대각선도 같은 속도로 이동합니다.
- 반대 방향키를 동시에 누르면 같은 축의 입력이 상쇄됩니다. 하나를 떼면 남은 키 방향으로 이동합니다.
- 이동 중에는 MOVE, 정지 중에는 IDLE 애니메이션을 초당 10프레임으로 재생합니다.
- 좌우 이동 후 상하 이동하거나 정지해도 마지막 시선을 유지합니다.
- 화면 경계에서는 캐릭터의 표시 영역 전체가 화면 안에 남습니다. 완전히 막히면 IDLE, 벽을 따라 이동하면 MOVE 애니메이션을 재생합니다.

화면 크기, 프레임 정보, 이동 속도, 애니메이션 속도는 `character_move_TUK.py` 상단의 상수에서 확인할 수 있습니다.

```powershell
python -m unittest discover -s tests -v
```
